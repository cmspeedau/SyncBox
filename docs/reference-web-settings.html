One page, slim shell. The whole settings page is three blocks: About server (server name, version + update check, backend & data dir, agent installers), Change password (vault-key rewrap; zero-knowledge — no server-side reset), Snapshots (Take a snapshot → POST /admin/backups, per-snapshot Verify → POST /admin/backups/{id}/verify, and the schedule select — changeable per the earlier decision → PUT /admin/backups/config, applied without restart; SYNCBOX_BACKUP_* env stays as fallback; when unconfigured, the card becomes the Set up S3 connection form). Everything else is deliberately not web UI: profile fields, notifications, 2FA / recovery kit / web sessions, device pairing, user admin, backup target / retention / hooks — those tasks stay CLI (syncbox users, syncbox backup restore) and env config; device-side settings live in the agent Settings window (reference-agent-settings.md). Sidebar: an All Vaults pill on top with a back chevron inside it (back to the vault list — the app root; search lives inside a vault), then the footer (quota · Settings active · Sign out).
