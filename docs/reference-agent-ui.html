    Two windows in this mock: main (status + vault list) and unlock (its own webview, so the password goes straight to the unlock command and never touches the main window). The gear opens a click menu — Settings… (a window of its own, designed in reference-agent-settings.html), Pause syncing / Resume syncing, and Quit (red, under a divider). First run: Connect (address + server password → token) → list_vaults → picker rows ← VaultChoice; Save & unlock lands on the vault list with the unlock window up for the chosen vault. Locking is per-vault: a locked row dims its icon and carries a grey chip + Unlock. States: SyncState → dot, AgentStatus → banners/passes. Pause remains the one new agent concept. Pass 2: the default flow is sign in → pick from server → auto folder → unlock — the sync folder is the server-derived one, shown read-only, and the advanced controls (＋ New vault name-only, Enter id by hand, extra sync folders) appear only when Show hidden features is on in settings — tick the demo checkbox to see them revealed.
