Three Tauri windows: main (status + activity), unlock (its own webview, so the password goes straight from that window to unlock and never touches the main window), settings (reads agent status/Config, writes through existing commands: set_autostart, pause, open-folder; Switch… reopens the first-run picker). First run: Connect → list_vaults, rows ← VaultChoice. Everyday states: SyncState → dot, AgentStatus → lines, history() → activity, Index → usage/passes. Pause remains the one new agent concept.
