Vaults

Vaults live here, on the server. Set one up, then point clients at this address with --vault-id. Encryption keys are made and kept on each client — setting a vault up here does not hand anyone the ability to read it. The folder below is where a vault's files land on every client, relative to that client's home directory.

Snapshots

A snapshot is a complete, sealed copy of everything this server holds — every vault's chunks and the bookkeeping — written to the configured backup target. It stays ciphertext: taking one never touches a key, and a stolen snapshot is no more readable than a stolen server. Snapshots cover the whole server, not one vault.
